## Test commands

```sh
pytest -q --junitxml=evidence/public/backend.xml
cd frontend
npm ci
npm run generate:api
npm run lint
npm run typecheck
npm run build
npm run test:unit
npm run test:e2e
```

The browser suite requires the seeded real runtime described in `frontend/README.md`. It does not intercept CRM responses with fabricated success. Controlled external provider adapters are isolated in the test runtime. Network-error tests abort transport; authorization rejection tests change a real membership and observe the backend response.

Backend additions are localized to `tests/test_checkpoint4.py` and the route/service files listed in the implementation report. Historical migrations and the 116-test baseline are checked unchanged in CI.
